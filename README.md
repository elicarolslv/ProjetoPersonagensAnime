# 🎌 Projeto Personagens Anime

Este projeto foi desenvolvido como um ambiente prático de estudos para consolidação de conceitos em desenvolvimento Java Web, manipulação de banco de dados relacional e versionamento de código utilizando Git. A aplicação permite o gerenciamento e a interação com informações estruturadas de personagens de anime.

---

## 🎯 Objetivos do Projeto
- Implementar as operações essenciais de um sistema dinâmico conectado a um banco de dados.
- Praticar a integração entre a camada de persistência (SQL) e a lógica de negócio em Java.
- Desenvolver e estruturar a interface na camada Web (servlets/JSPs ou páginas estruturadas na pasta `web`).
- Exercitar boas práticas de versionamento com Git (fluxo de ramificação, commits e merges).

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem Principal:** Java (Java Web / Servlets)
- **Camada Web:** HTML, CSS e componentes de layout dinâmicos
- **Banco de Dados:** SQL (Script de persistência estruturado)
- **IDE Recomendada:** NetBeans (Configurações integradas via `nbproject` e `build.xml`)

---

## 📁 Estrutura do Repositório

O projeto segue a estrutura padrão de uma aplicação Java Web estruturada no NetBeans:

- `/src`: Contém as classes Java, lógica de negócio, controladores e regras de conexão.
- `/web`: Páginas da interface do usuário, folhas de estilo (CSS) e arquivos estruturais do Front-End.
- `/lib`: Bibliotecas e drivers externos utilizados pelo projeto (como o driver JDBC para conexão com o banco).
- `personagem_anime.sql`: Script contendo a estrutura das tabelas e dados iniciais para popular o banco de dados.
